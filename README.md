# DoomScroll

> TikTok API built into an unblocked site.

**DoomScroll** is a TikTok-focused web project that combines a TikTok API with an unblocked website, allowing users to browse TikTok content without the usual restrictions.

## Features

* TikTok API integration
* Built into an unblocked website
* Fast and lightweight
* TikTok-style browsing experience
